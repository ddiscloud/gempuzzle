❓ 도움말

🎯 목표

흩어진 보석들을 올바른 칸에 모두 배치해 픽셀 아트 그림을 완성하세요.
각 칸에는 정해진 정답 색이 있고, 같은 색 보석을 그 자리에 놓으면 됩니다.

🖱️ 기본 조작

  • 보석 클릭 → 선택 (이미 정답 위치에 있거나 빈 칸은 선택 불가)
  • 같은 색이 인접하면 8방향(대각선 포함)으로 자동 묶음 선택
  • 보석 선택 후 빈 칸 클릭 → 이동 (목적지 정답 색과 일치하는 보석만 이동)
  • 선택된 보석을 다시 클릭하면 선택 해제

📦 버퍼

화면 아래 임시 보관 공간입니다. 막힌 보석을 비켜두고 경로를 열 때 활용하세요.

  • 보석 선택 후 빈 버퍼 슬롯 클릭 → 보관
  • 버퍼 슬롯 클릭 → 같은 색 전체 선택 → 빈 칸 클릭으로 배치
  • 시작 시 12칸, 색 하나 완성마다 3칸 추가 (최대 30칸)

✨ 색 완성 보너스

한 색의 보석이 모두 정답 위치에 놓이면 반짝임 효과와 함께 버퍼 슬롯 3칸이 추가로 해금됩니다.

💡 팁

버퍼를 적극 활용하세요. 막혀있는 보석을 버퍼에 옮기면 이동 경로가 열립니다.
작은 색부터 완성하세요. 면적이 작은 색을 먼저 끝내면 버퍼를 빠르게 늘릴 수 있어요.
덩어리를 노리세요. 같은 색이 뭉칠수록 한 번에 많이 이동해 이동 횟수를 줄일 수 있습니다.
마우스를 올려 색을 확인하세요. 좌상단에 해당 칸의 정답 색과 현재 보석 색이 동시에 표시됩니다.
